# Project 42: Heartbeat Sensor - Pin Connections

## Components Needed
- 1 x Pulse Sensor / Heartbeat Sensor Module
- Jumper Wires

## Library Note
This project uses a simplified version of the logic from the **PulseSensor Playground** library. For more advanced features and accurate readings, it is highly recommended to install that library from the Arduino Library Manager.

## Connections
-   **Pulse Sensor Module**:
    -   **S** (Signal) -> **A0** on Arduino
    -   **+** (VCC) -> **5V** on Arduino
    -   **-** (GND) -> **GND** on Arduino
