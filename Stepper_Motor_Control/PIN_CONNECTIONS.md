# Project 26: Stepper Motor Control - Pin Connections

## Components Needed
- 1 x 28BYJ-48 Stepper Motor
- 1 x ULN2003 Stepper Motor Driver Board
- Jumper Wires

## Connections
-   **ULN2003 Driver Board**:
    -   **IN1** -> **Arduino Pin 8**
    -   **IN2** -> **Arduino Pin 9**
    -   **IN3** -> **Arduino Pin 10**
    -   **IN4** -> **Arduino Pin 11**
    -   **+** (Power) -> **5V** on Arduino
    -   **-** (Ground) -> **GND** on Arduino
-   **Stepper Motor**:
    -   Plug the motor's 5-pin connector into the socket on the ULN2003 driver board.
