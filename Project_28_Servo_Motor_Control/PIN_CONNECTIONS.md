# Project 28: Servo Motor Control - Pin Connections

## Components Needed
- 1 x SG90 or similar small servo motor
- Jumper Wires

## Connections
-   **Servo Motor**:
    -   **Brown wire (GND)** -> **GND** on Arduino
    -   **Red wire (VCC)** -> **5V** on Arduino
    -   **Orange wire (Signal)** -> **Pin 9** on Arduino
