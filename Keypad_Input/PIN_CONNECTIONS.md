# Project 45: Keypad Input - Pin Connections

## Components Needed
- 1 x 4x4 Matrix Keypad
- Jumper Wires

## Library Needed
- **Keypad**: Install this library from the Arduino IDE's Library Manager. It is by **Mark Stanley** and **Alexander Brevig**.

## Connections
The pins on the keypad correspond to the rows and columns. They are usually numbered 1 to 8 from left to right.

-   **Keypad Pin 1 (Row 1)** -> **Arduino Pin 9**
-   **Keypad Pin 2 (Row 2)** -> **Arduino Pin 8**
-   **Keypad Pin 3 (Row 3)** -> **Arduino Pin 7**
-   **Keypad Pin 4 (Row 4)** -> **Arduino Pin 6**
-   **Keypad Pin 5 (Col 1)** -> **Arduino Pin 5**
-   **Keypad Pin 6 (Col 2)** -> **Arduino Pin 4**
-   **Keypad Pin 7 (Col 3)** -> **Arduino Pin 3**
-   **Keypad Pin 8 (Col 4)** -> **Arduino Pin 2**
