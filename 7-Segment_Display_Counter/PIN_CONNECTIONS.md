# Project 13: 7-Segment Display Counter - Pin Connections

## Components Needed
- 1 x Common Cathode 7-Segment Display
- 7 x 220Ω Resistors
- Jumper Wires

## Connections
Connect each segment pin of the display through a 220Ω resistor to the corresponding Arduino pin.

-   Segment **a** -> Resistor -> **Pin 2**
-   Segment **b** -> Resistor -> **Pin 3**
-   Segment **c** -> Resistor -> **Pin 4**
-   Segment **d** -> Resistor -> **Pin 5**
-   Segment **e** -> Resistor -> **Pin 6**
-   Segment **f** -> Resistor -> **Pin 7**
-   Segment **g** -> Resistor -> **Pin 8**

The common cathode pin of the display connects to **GND**.
