# Project 33: RTC Temperature Logger - Pin Connections

## Components Needed
- 1 x DS3231 Real-Time Clock Module
- Jumper Wires

## Library Needed
- **RTClib** by Adafruit.

## Connections
This project uses the exact same wiring as **Project 32 (Real-Time Clock)**.

-   **DS3231 Module** -> **Arduino Uno/Nano**
    -   **VCC** -> **5V**
    -   **GND** -> **GND**
    -   **SDA** -> **A4**
    -   **SCL** -> **A5**
