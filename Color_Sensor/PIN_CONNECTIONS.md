# Project 56: Color Sensor (TCS3200/TCS230) - Pin Connections

## Components Needed
- 1 x TCS3200 or TCS230 Color Sensor Module
- Jumper Wires

## Connections
-   **TCS3200 Module** -> **Arduino Uno/Nano**
    -   **S0** -> **Pin 4**
    -   **S1** -> **Pin 5**
    -   **S2** -> **Pin 6**
    -   **S3** -> **Pin 7**
    -   **OUT** -> **Pin 8**
    -   **VCC** -> **5V**
    -   **GND** -> **GND**
