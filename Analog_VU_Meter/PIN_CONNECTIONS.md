# Project 66: Analog VU Meter - Pin Connections

## Components Needed
- 1 x Microphone Sound Sensor Module
- 1 x SG90 Servo Motor
- Jumper Wires

## Connections
-   **Sound Sensor Module**:
    -   **A0** (Analog Output) -> **A0** on Arduino
    -   **VCC** -> **5V**
    -   **GND** -> **GND**
-   **Servo Motor**:
    -   **Signal** -> **Pin 9**
    -   **VCC** -> **5V**
    -   **GND** -> **GND**
