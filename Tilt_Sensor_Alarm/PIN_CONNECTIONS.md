# Project 21: Tilt Sensor Alarm - Pin Connections

## Components Needed
- 1 x Tilt Sensor (the kind with two pins, often a ball in a tube)
- 1 x Piezo Buzzer
- Jumper Wires

## Connections
-   **Tilt Sensor**:
    -   One pin -> **Pin 2**
    -   The other pin -> **GND**
-   **Buzzer**:
    -   Positive (+) leg -> **Pin 8**
    -   Negative (-) leg -> **GND**
