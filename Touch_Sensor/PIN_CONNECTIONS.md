# Project 39: Touch Sensor - Pin Connections

## Components Needed
- 1 x Capacitive Touch Sensor Module (e.g., TTP223B)
- 1 x LED
- 1 x 220Ω Resistor
- Jumper Wires

## Connections
-   **Touch Sensor Module**:
    -   **SIG** (Signal) -> **Pin 2** on Arduino
    -   **VCC** -> **5V** on Arduino
    -   **GND** -> **GND** on Arduino
-   **LED**:
    -   Anode (+) -> 220Ω Resistor -> **Pin 8**
    -   Cathode (-) -> **GND**
