# Project 35: Soil Moisture Sensor - Pin Connections

## Components Needed
- 1 x Soil Moisture Sensor Module (usually comes with a probe and a small amplifier board)
- Jumper Wires

## Connections
-   **Sensor Probe**:
    -   Connect the two pins of the probe to the two corresponding pins on the amplifier board.
-   **Amplifier Board**:
    -   **A0** (Analog Output) -> **A0** on Arduino
    -   **VCC** -> **5V** on Arduino
    -   **GND** -> **GND** on Arduino
    -   **D0** (Digital Output) -> (not used in this project)
