# Project 19: Moisture Sensor - Pin Connections

## Components Needed
- 1 x Soil Moisture Sensor Module (e.g., YL-69 or HL-69)
- Jumper Wires

## Connections
-   **Moisture Sensor Module**:
    -   **VCC** -> **5V** on Arduino
    -   **GND** -> **GND** on Arduino
    -   **A0** (Analog Output) -> **A0** on Arduino
    -   Connect the two prongs of the sensor probe to the two terminals on the module.
