# Project 44: Rotary Encoder - Pin Connections

## Components Needed
- 1 x Rotary Encoder Module
- Jumper Wires

## Connections
-   **Rotary Encoder Module**:
    -   **CLK** (Clock) -> **Pin 2** on Arduino
    -   **DT** (Data) -> **Pin 3** on Arduino
    -   **SW** (Switch) -> (not used in this project)
    -   **+** (VCC) -> **5V** on Arduino
    -   **GND** -> **GND** on Arduino
