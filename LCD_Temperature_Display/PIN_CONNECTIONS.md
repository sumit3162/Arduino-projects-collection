# Project 24: LCD Temperature Display - Pin Connections

## Components Needed
- 1 x 16x2 LCD Display
- 1 x TMP36 Temperature Sensor
- 1 x 10kΩ Potentiometer
- Jumper Wires

## Connections
-   **LCD Connections**: Same as Project 23.
    -   RS -> Pin 12
    -   E -> Pin 11
    -   D4 -> Pin 5
    -   D5 -> Pin 4
    -   D6 -> Pin 3
    -   D7 -> Pin 2
    -   VSS, R/W, LED- to GND
    -   VDD, LED+ to 5V
    -   VO to potentiometer wiper.
-   **TMP36 Sensor**:
    -   Pin 1 (left) -> **5V**
    -   Pin 2 (middle) -> **A0**
    -   Pin 3 (right) -> **GND**
