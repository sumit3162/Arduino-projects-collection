# Project 5: Push Button LED Control - Pin Connections

## Components Needed
- 1 x LED
- 1 x 220Ω Resistor
- 1 x Push Button
- 1 x 10kΩ Resistor (for pull-down)
- Jumper Wires

## Connections
-   **LED**:
    -   Anode -> 220Ω Resistor -> **Pin 13**
    -   Cathode -> **GND**
-   **Push Button**:
    -   One terminal to **5V**.
    -   The other terminal to **Pin 2**.
    -   The same terminal connected to Pin 2 also connects to one end of the 10kΩ resistor. The other end of the resistor goes to **GND**.
