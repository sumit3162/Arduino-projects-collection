# Arduino Projects Collection

This repository contains a collection of over 100 Arduino projects for all skill levels.

## Project Ideas

### Beginner

1.  **Blinking LED**: The "Hello, World!" of microcontrollers.
2.  **Fading LED**: Control LED brightness with PWM.
3.  **Knight Rider LED Scanner**: Create a Knight Rider-style LED scanner.
4.  **Traffic Light Controller**: Simulate a traffic light sequence.
5.  **Push Button LED Control**: Turn an LED on and off with a button.
6.  **Potentiometer LED Control**: Control LED brightness with a potentiometer.
7.  **Photoresistor Light Detector**: Turn on an LED in the dark.
8.  **Temperature Sensor Display**: Display temperature on the Serial Monitor.
9.  **Simple Alarm System**: Use a PIR sensor to detect motion and sound a buzzer.
10. **Servo Motor Control**: Control a servo motor with a potentiometer.
11. **RGB LED Color Mixer**: Mix colors with an RGB LED and potentiometers.
12. **Ultrasonic Distance Sensor**: Measure distance and display it on the Serial Monitor.
13. **7-Segment Display Counter**: Create a simple counter.
14. **DC Motor Speed Control**: Control the speed of a DC motor with a transistor and PWM.
15. **Relay Control**: Control a high-power device (like a lamp) with a relay.
16. **Tone Generator**: Create simple tones with a piezo buzzer.
17. **Simon Says Game**: A simple memory game with LEDs and buttons.
18. **Digital Hourglass**: Use LEDs to simulate an hourglass.
19. **Moisture Sensor**: Detect moisture in soil.
20. **Flex Sensor Glove**: Control an LED with a flex sensor.
21. **Tilt Sensor Alarm**: Sound an alarm when an object is tilted.
22. **IR Remote Control**: Decode signals from an IR remote.
23. **LCD "Hello, World!"**: Display text on an LCD screen.
24. **LCD Temperature Display**: Show temperature on an LCD.
25. **LCD Clock**: A simple digital clock using an LCD.
26. **Sound Detector**: Turn on an LED when a loud sound is detected.
27. **Joystick Control**: Control a servo or LED with a joystick module.
28. **Water Level Sensor**: Create a simple water level indicator.
29. **Fan Speed Controller**: Control a computer fan with a potentiometer.
30. **Simple Piano**: Create a simple piano with buttons and a buzzer.
31. **Reaction Time Game**: Test your reaction time.
32. **Laser Tripwire**: Use a laser and a photoresistor to create a tripwire.
33. **Automatic Night Light**: A more advanced version of the photoresistor project.
34. **LED Dice**: Simulate a dice roll with LEDs.
