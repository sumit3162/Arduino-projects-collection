# Project 3: Knight Rider - Pin Connections

## Components Needed
- 6 x LEDs (any color)
- 6 x 220Ω or 330Ω Resistors
- Jumper Wires

## Connections
Connect each of the six LEDs to the Arduino through a current-limiting resistor.

-   **LED 1**:
    -   Anode -> Resistor -> **Pin 2**
    -   Cathode -> **GND**
-   **LED 2**:
    -   Anode -> Resistor -> **Pin 3**
    -   Cathode -> **GND**
-   **LED 3**:
    -   Anode -> Resistor -> **Pin 4**
    -   Cathode -> **GND**
-   **LED 4**:
    -   Anode -> Resistor -> **Pin 5**
    -   Cathode -> **GND**
-   **LED 5**:
    -   Anode -> Resistor -> **Pin 6**
    -   Cathode -> **GND**
-   **LED 6**:
    -   Anode -> Resistor -> **Pin 7**
    -   Cathode -> **GND**

**Note**: All LED cathodes can be connected to a common ground rail on a breadboard, which is then connected to a single GND pin on the Arduino.
