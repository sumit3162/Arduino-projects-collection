# Project 46: Keypad Door Lock - Pin Connections

## Components Needed
- 1 x 4x4 Matrix Keypad
- 1 x SG90 Servo Motor
- Jumper Wires

## Libraries Needed
- **Keypad**
- **Servo**

## Connections
-   **Keypad**: Same wiring as Project 45.
    -   Row 1 -> Pin 9
    -   Row 2 -> Pin 8
    -   Row 3 -> Pin 7
    -   Row 4 -> Pin 6
    -   Col 1 -> Pin 5
    -   Col 2 -> Pin 4
    -   Col 3 -> Pin 3
    -   Col 4 -> Pin 2
-   **Servo Motor**:
    -   Signal -> **Pin 10**
    -   VCC -> **5V**
    -   GND -> **GND**
