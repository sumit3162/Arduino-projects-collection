# Project 37: Flame Sensor - Pin Connections

## Components Needed
- 1 x Flame Sensor Module
- 1 x LED (optional)
- Jumper Wires

## Connections
-   **Flame Sensor Module**:
    -   **D0** (Digital Output) -> **Pin 2** on Arduino
    -   **VCC** -> **5V** on Arduino
    -   **GND** -> **GND** on Arduino
-   **LED**:
    -   The code uses the built-in LED on **Pin 13**.
