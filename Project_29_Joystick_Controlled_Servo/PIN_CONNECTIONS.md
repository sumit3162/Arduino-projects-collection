# Project 29: Joystick Controlled Servo - Pin Connections

## Components Needed
- 1 x Analog Joystick Module
- 1 x SG90 Servo Motor
- Jumper Wires

## Connections
-   **Joystick Module**:
    -   **GND** -> **GND** on Arduino
    -   **+5V** -> **5V** on Arduino
    -   **VRx** (X-axis output) -> **A0** on Arduino
    -   **VRy** (Y-axis output) -> (not used in this project)
    -   **SW** (Switch) -> (not used in this project)
-   **Servo Motor**:
    -   **Brown wire (GND)** -> **GND**
    -   **Red wire (VCC)** -> **5V**
    -   **Orange wire (Signal)** -> **Pin 9**
