# Project 47: Dot Matrix Display - Pin Connections

## Components Needed
- 1 x MAX7219 8x8 Dot Matrix Module
- Jumper Wires

## Library Needed
- **LedControl**: Install from the Arduino IDE's Library Manager.

## Connections
-   **MAX7219 Module** -> **Arduino Uno/Nano**
    -   **VCC** -> **5V**
    -   **GND** -> **GND**
    -   **DIN** (Data In) -> **Pin 12**
    -   **CS** (Chip Select) -> **Pin 10**
    -   **CLK** (Clock) -> **Pin 11**
