# Project 4: Traffic Light Controller - Pin Connections

## Components Needed
- 1 x Red LED
- 1 x Yellow LED
- 1 x Green LED
- 3 x 220Ω or 330Ω Resistors
- Jumper Wires

## Connections
-   **Red LED**:
    -   Anode -> Resistor -> **Pin 10**
    -   Cathode -> **GND**
-   **Yellow LED**:
    -   Anode -> Resistor -> **Pin 9**
    -   Cathode -> **GND**
-   **Green LED**:
    -   Anode -> Resistor -> **Pin 8**
    -   Cathode -> **GND**

All cathodes connect to a common ground.
