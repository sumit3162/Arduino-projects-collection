# Project 18: Digital Hourglass - Pin Connections

## Components Needed
- 6 x LEDs
- 6 x 220Ω Resistors
- Jumper Wires

## Connections
-   **LED 1**: Anode -> Resistor -> **Pin 2**, Cathode -> **GND**
-   **LED 2**: Anode -> Resistor -> **Pin 3**, Cathode -> **GND**
-   **LED 3**: Anode -> Resistor -> **Pin 4**, Cathode -> **GND**
-   **LED 4**: Anode -> Resistor -> **Pin 5**, Cathode -> **GND**
-   **LED 5**: Anode -> Resistor -> **Pin 6**, Cathode -> **GND**
-   **LED 6**: Anode -> Resistor -> **Pin 7**, Cathode -> **GND**
