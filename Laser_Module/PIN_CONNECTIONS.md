# Project 40: Laser Module - Pin Connections

## Components Needed
- 1 x Laser Diode Module
- Jumper Wires

## !! WARNING !!
-   **Never look directly into the laser beam or point it at anyone's eyes. It can cause permanent eye damage.**
-   Use this module responsibly.

## Connections
-   **Laser Module**:
    -   **S** (Signal) pin -> **Pin 8** on Arduino
    -   **VCC** or **+** pin -> **5V** on Arduino
    -   **GND** or **-** pin -> **GND** on Arduino
    
    *Note: Some modules may only have two pins. In that case, connect the signal pin to Pin 8 and the other pin to GND.*
