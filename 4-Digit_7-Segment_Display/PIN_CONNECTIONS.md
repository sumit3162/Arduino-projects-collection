# Project 64: 4-Digit 7-Segment Display - Pin Connections

## Components Needed
- 1 x 4-Digit 7-Segment Display Module (with TM1637 driver)
- Jumper Wires

## Library Needed
- **TM1637** by Avishay Orpaz. Install from the Arduino IDE's Library Manager.

## Connections
-   **TM1637 Module** -> **Arduino Uno/Nano**
    -   **VCC** -> **5V**
    -   **GND** -> **GND**
    -   **CLK** (Clock) -> **Pin 2**
    -   **DIO** (Data I/O) -> **Pin 3**
