# Project 51: OLED Display "Hello World" - Pin Connections

## Components Needed
- 1 x 0.96" I2C OLED Display (128x64)
- Jumper Wires

## Libraries Needed
- **Adafruit GFX Library**
- **Adafruit SSD1306 Library**
- Install both from the Arduino IDE's Library Manager.

## Connections (I2C)
-   **OLED Display** -> **Arduino Uno/Nano**
    -   **VCC** -> **5V**
    -   **GND** -> **GND**
    -   **SDA** -> **A4**
    -   **SCL** -> **A5**
