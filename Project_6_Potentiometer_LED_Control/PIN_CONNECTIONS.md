# Project 6: Potentiometer LED Control - Pin Connections

## Components Needed
- 1 x LED
- 1 x 220Ω Resistor
- 1 x 10kΩ Potentiometer
- Jumper Wires

## Connections
-   **LED**:
    -   Anode -> 220Ω Resistor -> **Pin 9**
    -   Cathode -> **GND**
-   **Potentiometer**:
    -   Outer pin 1 -> **5V**
    -   Center pin (wiper) -> **A0**
    -   Outer pin 2 -> **GND**
