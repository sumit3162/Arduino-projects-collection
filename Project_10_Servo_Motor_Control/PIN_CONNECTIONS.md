# Project 10: Servo Motor Control - Pin Connections

## Components Needed
- 1 x Servo Motor (e.g., SG90)
- 1 x 10kΩ Potentiometer
- Jumper Wires

## Connections
-   **Servo Motor**:
    -   Red wire (VCC) -> **5V**
    -   Brown/Black wire (GND) -> **GND**
    -   Orange/Yellow wire (Signal) -> **Pin 9**
-   **Potentiometer**:
    -   Outer pin 1 -> **5V**
    -   Center pin (wiper) -> **A0**
    -   Outer pin 2 -> **GND**
