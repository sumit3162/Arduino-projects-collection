# Project 32: Real-Time Clock (RTC) - Pin Connections

## Components Needed
- 1 x DS3231 Real-Time Clock Module
- Jumper Wires

## Library Needed
- **RTClib** by Adafruit: Install from the Arduino IDE's Library Manager.

## Connections (I2C Interface)
-   **DS3231 Module** -> **Arduino Uno/Nano**
    -   **VCC** -> **5V**
    -   **GND** -> **GND**
    -   **SDA** (Serial Data) -> **A4**
    -   **SCL** (Serial Clock) -> **A5**
