# Project 27: Stepper Motor Speed Control - Pin Connections

## Components Needed
- 1 x 28BYJ-48 Stepper Motor
- 1 x ULN2003 Stepper Motor Driver Board
- 1 x 10kΩ Potentiometer
- Jumper Wires

## Connections
-   **Stepper Motor & Driver**: Same wiring as Project 26.
    -   IN1 -> Pin 8
    -   IN2 -> Pin 9
    -   IN3 -> Pin 10
    -   IN4 -> Pin 11
    -   Driver Power (+) -> 5V
    -   Driver Ground (-) -> GND
-   **Potentiometer**:
    -   One outer pin -> **5V**
    -   The other outer pin -> **GND**
    -   Center pin -> **A0**
