# Project 17: Simon Says Game - Pin Connections

## Components Needed
- 4 x LEDs (e.g., Red, Green, Blue, Yellow)
- 4 x Push Buttons
- 4 x 220Ω Resistors (for LEDs)
- 1 x Piezo Buzzer
- Jumper Wires

## Connections
-   **LEDs**:
    -   LED 1 Anode -> 220Ω Resistor -> **Pin 2**
    -   LED 2 Anode -> 220Ω Resistor -> **Pin 3**
    -   LED 3 Anode -> 220Ω Resistor -> **Pin 4**
    -   LED 4 Anode -> 220Ω Resistor -> **Pin 5**
    -   All LED Cathodes -> **GND**
-   **Buttons** (using internal pull-up resistors):
    -   Button 1 -> **Pin 8** and **GND**
    -   Button 2 -> **Pin 9** and **GND**
    -   Button 3 -> **Pin 10** and **GND**
    -   Button 4 -> **Pin 11** and **GND**
-   **Buzzer**:
    -   Positive (+) -> **Pin 12**
    -   Negative (-) -> **GND**
