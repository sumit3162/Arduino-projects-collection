# Project 43: Microphone Sound Sensor - Pin Connections

## Components Needed
- 1 x Microphone Sound Sensor Module
- Jumper Wires

## Connections
-   **Sound Sensor Module**:
    -   **A0** (Analog Output) -> **A0** on Arduino
    -   **GND** -> **GND** on Arduino
    -   **VCC** -> **5V** on Arduino
    -   **D0** (Digital Output) -> (not used in this project)
