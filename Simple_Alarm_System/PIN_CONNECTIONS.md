# Project 9: Simple Alarm System - Pin Connections

## Components Needed
- 1 x PIR Motion Sensor
- 1 x Piezo Buzzer
- Jumper Wires

## Connections
-   **PIR Sensor**:
    -   VCC -> **5V**
    -   OUT -> **Pin 2**
    -   GND -> **GND**
-   **Buzzer**:
    -   Positive (+) leg -> **Pin 8**
    -   Negative (-) leg -> **GND**
