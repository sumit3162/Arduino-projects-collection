# Project 61: Barometric Pressure Sensor (BMP180) - Pin Connections

## Components Needed
- 1 x BMP180 Barometric Pressure Sensor Module
- Jumper Wires

## Library Needed
- **Adafruit BMP085 Library**: Install from the Arduino IDE's Library Manager. This library is compatible with the BMP180.

## Connections (I2C)
-   **BMP180 Module** -> **Arduino Uno/Nano**
    -   **VIN** or **VCC** -> **5V**
    -   **GND** -> **GND**
    -   **SCL** -> **A5**
    -   **SDA** -> **A4**
