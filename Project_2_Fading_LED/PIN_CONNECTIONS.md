# Project 2: Fading LED - Pin Connections

## Components Needed
- 1 x LED (any color)
- 1 x 220Ω or 330Ω Resistor
- Jumper Wires

## Connections
1.  Connect the **anode** (the longer leg) of the LED to one end of the resistor.
2.  Connect the other end of the resistor to **Pin 9** on the Arduino.
3.  Connect the **cathode** (the shorter leg) of the LED to **GND** (Ground) on the Arduino.

### Diagram
```
              +-----------+
              |           |
LED Anode ----|  Resistor |---- Arduino Pin 9
              |           |
              +-----------+

LED Cathode ----------------- Arduino GND
```
