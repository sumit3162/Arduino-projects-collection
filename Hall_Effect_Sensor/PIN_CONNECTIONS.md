# Project 38: Hall Effect Sensor - Pin Connections

## Components Needed
- 1 x Hall Effect Sensor Module (e.g., KY-024)
- 1 x Small Magnet
- Jumper Wires

## Connections
-   **Hall Effect Sensor Module**:
    -   **D0** (Digital Output) -> **Pin 2** on Arduino
    -   **VCC** or **+** -> **5V** on Arduino
    -   **GND** -> **GND** on Arduino
